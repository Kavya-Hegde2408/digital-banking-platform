#Digital Banking Platform

A production-oriented Spring Boot backend application built to learn and demonstrate enterprise backend development concepts.

## Tech Stack

* Java 21
* Spring Boot 3
* Spring Security
* JWT Authentication
* Spring Data JPA
* PostgreSQL
* MapStruct
* JUnit 5
* Mockito
* Docker

## Features

* User Registration
* User Login
* JWT Authentication
* Role Based Access Control
* Customer Management
* Account Management
* Beneficiary Management
* Money Transfer
* Transaction History
* Pagination & Search
* Unit Testing
* Docker Support

## Future Enhancements

* Redis Caching
* Kafka Integration
* Monitoring
* Microservices
